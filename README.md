#Sorting Algorithm Performance Analysis

C++ project that implements and compares the performance of different sorting algorithms on arrays with different sizes and levels of sortedness.

##Algorithms

-Selection Sort
-Insertion Sort
-Bubble Sort

##Test Cases

The algorithms are tested using different types of input data:

-Random arrays
-90% sorted arrays
-50% sorted arrays

The program measures the execution time of each sorting algorithm and saves the results to a CSV file.

#Input Sizes 

The program tests multiple input sizes to compare how sorting performance changes as the amount of data increases. 

##Technologies

-C++
-STL `vector`
-Sorting algorithms
-`chrono` for runtime measurement
-File I/O
CSV data analysis
